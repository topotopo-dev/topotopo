# TopoTopo v0.5.3

Release date: 2026-11-05. Fixes from a second production kit, mostly materials, rendering and export.

- `boolean`: each input's overlapping pieces are unioned before the operation, so a cutter made of several
  overlapping solids cuts the whole of its volume and the cut faces carry its material. A boolean without a second
  input keeps cavities instead of filling them.
- PBR render: a named material's colour now wins over `Cd` as documented; `--cd auto|ignore|multiply` controls it.
  Alpha mask and blend materials render as such (holes in grates, tint through glass). `--grey` renders every base
  colour as neutral grey for value checks. The preview multiplies an ORM map by the material's roughness and
  metallic factors exactly as the glTF export does.
- glTF export: vertex alpha in `COLOR_0` no longer promotes an opaque material to `alphaMode: BLEND`; with an ORM map
  the roughness and metallic factors default to 1 and `roughness_value` / `metallic_value` are the factors;
  `materials.json` agrees with the GLB; the collapsed-UV warning skips thin triangles (card sides) so real
  warnings stay visible.
- Export from a followed working folder: `--follow <package>` (CLI) and `follow: [...]` (MCP export) export from the
  package's working folder when it has no published version yet; the export's source record says so under
  `followed`. Without it the refusal says what to do; `--locked` still refuses.
- Textures: `tex_pattern` stripes honour the v count; `tex_transform` tiles from the corner, so cells align without
  an offset.
- `uv_project` gains a `group` param, so the end annuli of a cylinder can get their own projection.
- Docs: extrude plane directions, revolve partial angles and open profiles, cylindrical uv_project scale, grid_split
  after a boolean, sweep end caps, the tex_grunge scale clamp.
