# TopoTopo v0.5.2

Release date: 2026-11-04. Four fixes from production use, no new features.

- Tangents: the MikkTSpace WebAssembly module grew its heap on every call and never released it, so after enough
  large previews, exports or bakes in one process every tangent computation failed with "offset is out of bounds".
  Pointers are now handled unsigned and the module is restarted once its heap passes 256 MiB. A single export above
  roughly nine million tangent triangles now fails with a clear "ran out of WebAssembly memory" message.
- Viewer: a preview that cannot be written or parsed is reported in the cook line as "preview failed: …" (with the
  stack on the server's stderr) instead of silently keeping the previous mesh.
- Viewer: the session re-attaches its file watchers when a package's `graphs/` or `assets/` folder is removed and
  recreated (a git checkout, for example); before, the editor stayed empty until the server restarted.
- CLI: `--version` prints the version only as the first argument, so `topotopo use <package> --version <v>` reaches
  the command.
- Engine cache: image, heightfield and SDF buffers now count toward the cache budget, each shared buffer once.
