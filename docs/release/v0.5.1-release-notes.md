# TopoTopo v0.5.1

Release date: pending.

The software renderer gains two opt-in options. `bounds` (CLI `--bounds x0,y0,z0,x1,y1,z1`) makes every 3D view frame
fixed world-space bounds instead of the geometry's own, so a sequence of renders, such as the frames of a timelapse or
the azimuths of a turntable, shares one camera. `footer: false` (CLI `--no-footer`) leaves out the footer strip, so the
image is exactly the views. Nothing else changed: without the options every render is identical to v0.5.
