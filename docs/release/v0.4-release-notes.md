# TopoTopo v0.4

Release date: 2026-10-27. A web app for libraries of packages, the pieces a hard-surface asset needs on its way into
an engine (constant-thickness shells, tangents, attachment sockets, a PBR preview, a UV report), image cutouts and
atlases, and fixes to UV unwrapping, bevels and normal-map bakes. Graphs from v0.3 cook unchanged: the graph format
is still version 1. 230 node types (six new), 37 shelf assets, 35 example graphs.

## Web app

A library is a folder listed in `~/.topotopo/config.json`; a package is any folder in it with an `<id>.topo` file, a
workspace of its own plus `attachments/` for concept art and references.

```bash
topotopo library add game D:/game-assets
topotopo library new game props/lantern --title "Lantern" --tags prop
topotopo web
```

`topotopo web` serves every library on http://127.0.0.1:7340: a grid by collection with search and tags, and a
page per package with a 3D view, links, attachments, graphs and their vars, and exports. Each page has copy boxes for
a link, an image and an embed (`/embed/<library>/<id>`) to put the package on a board. Previews (a thumbnail and a
compressed GLB) bake in the background when a package's graphs or inputs change; a failed bake keeps the previous
files. Agents reach the libraries through the MCP `workspace` tool: list and search, read a package, create one,
edit its manifest, bake, and open a package as the folder every tool and the live viewer work in.

## Hard-surface assets

- **`solidify`** (alias `shell`) turns a surface into a wall of constant thickness: each point moves by the
  least-squares solution of its faces' offset planes, so folds and corners keep the thickness. `offset` grows the wall
  inside, centred or outside; `fill_rim` closes open boundaries; groups `outer`, `inner` and `rim`. Inputs and
  results it cannot build cleanly (non-manifold edges, inconsistent winding, runaway mitres, self-intersections) are
  refused with a message that says what and where, never thinned silently. `assert` gains `strict_intersections`.
- **Tangents**: normal-mapped glTF primitives get MikkTSpace `TANGENT`s, so importers no longer generate their own
  basis. Export option `tangents`: `auto` (default), `preserve`, `none` (CLI `--tangents`, MCP `export tangents`).
  Import reads `TANGENT` into point `tangent`, and transforms carry it. `bake_normal` bakes in the same frame, so a
  baked map decodes exactly with the exported tangents.
- **Attachment sockets**: `scene_null` adds a named empty (translation, rotation, scale) under the scene root, another
  empty or a mesh part; glTF export writes empties as meshless nodes in the right place, also under quantized and
  Z-up / scaled exports, and import reads them back.
- **PBR preview**: renders take `shading: "pbr"`, which evaluates the exported metallic-roughness material (base
  colour, normal, occlusion/roughness/metallic, emissive, unlit) under a fixed studio rig. Same input, same PNG bytes.
  CLI `--shading pbr --exposure N`, MCP render and the library bake.
- **UV report**: `inspect` detail `uv` (CLI `--inspect uv`, MCP) lists missing, collapsed and out-of-tile triangles,
  charts, mirrored triangles, exact overlaps, utilization and per-part texel density.
- **Cleaner triangles**: quads no longer export zero-area slivers when a corner is nearly collinear, strongly
  non-planar polygons no longer fold, and `inspect` detail `topology` reports triangle health.

## Image cutouts and atlases

Four general nodes for cards and decals cut from images:

- `tex_crop` crops and resizes every layer of an image together.
- `trace_image` traces a thresholded channel into closed contours with holes, ready for `fill`.
- `tex_dilate` extends edge pixels into the transparent margin so mipmaps do not bleed.
- `tex_pack` packs named images into aligned atlases and outputs each item's UV offset and scale.

`material` gains `alpha_mode` (`auto`, `opaque`, `mask`, `blend`) and `alpha_cutoff`; masked materials stay masked in
GLB and in the live and headless previews. The workflow is in
[docs/image-cutouts.md](https://github.com/topotopo-dev/topotopo/blob/main/docs/image-cutouts.md), with
`examples/image_cutouts.json`.

## Fixes

- **UV unwrap**: parts a few centimetres across unwrap like large ones (no merged bevel corners, dropped faces or
  overlapping charts).
- **Bevel**: `clamp` shrinks offsets only where bevels would cross, so one short edge no longer flattens every bevel
  on the mesh; an edge that would keep almost nothing stays sharp, with a warning. `rounded_rect` no longer writes a
  repeated point where its corner arcs meet.
- **Normal-map bakes**: missing or zero normals on the high mesh (from merging parts with and without normals) are
  computed before baking instead of baking flat grey.
- **glTF export**: the empties' bookkeeping attributes no longer appear on mesh primitives.
- **Preview GLB**: sockets parented to a mesh keep their place in the web app's merged preview.
