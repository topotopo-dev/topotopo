# Machined bracket

A metal mounting bracket for a game prop or a print: an L-shaped plate with rounded edges, bolt holes in both legs and
an engraved label.

## In
- width: 0.05–0.5 m, default 0.15. Width of the bracket.
- leg: 0.05–0.5 m, default 0.12. Length of each leg of the L.
- thickness: 0.004–0.03 m, default 0.01. Thickness of the plate.
- holes: 1–6, default 2. Bolt holes in each leg.
- hole_size: 0.004–0.02 m, default 0.008. Diameter of every bolt hole.
- bevel: 0–0.002 m, default 0.001. Radius of the rounded edges.
- label: the text engraved on the upright face, default "TT-12".

## Out
- bracket (mesh): the bracket, one closed piece in brushed steel.

## Promises
- closed: the bracket is one closed piece, every face pointing out.
- holes: it has exactly twice as many bolt holes as holes, all the way through.
- size: it fits within width by leg and thickness on each side.

## Look
A clean steel L-bracket with softly rounded edges, round bolt holes in both legs and a crisp engraved label on the
upright face.
